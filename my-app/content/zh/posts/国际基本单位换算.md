## 引言

**国际单位制**（Système International d'Unités，简称 SI）是全球通用的度量衡标准。它共有 **七个基本单位**，分别对应七个基本物理量：

| 基本物理量 | 单位名称 | 单位符号 |
|------------|----------|----------|
| 长度       | 米       | m        |
| 质量       | 千克     | kg       |
| 时间       | 秒       | s        |
| 电流       | 安培     | A        |
| 热力学温度 | 开尔文   | K        |
| 物质的量   | 摩尔     | mol      |
| 发光强度   | 坎德拉   | cd       |

本文聚焦于前四个最为常用的单位，给出它们与常见衍生单位及非公制单位之间的换算关系。

---

## 一、长度单位换算（米）

### 1.1 米与常用公制单位

| 单位 | 换算关系（相对于 1 m） |
|------|------------------------|
| 千米（km） | $1\,\text{km} = 10^3\,\text{m}$ |
| 分米（dm） | $1\,\text{dm} = 10^{-1}\,\text{m}$ |
| 厘米（cm） | $1\,\text{cm} = 10^{-2}\,\text{m}$ |
| 毫米（mm） | $1\,\text{mm} = 10^{-3}\,\text{m}$ |
| 微米（μm） | $1\,\mu\text{m} = 10^{-6}\,\text{m}$ |
| 纳米（nm） | $1\,\text{nm} = 10^{-9}\,\text{m}$ |

### 1.2 米与英制单位（约等）

| 英制单位 | 换算关系（1 m ≈） |
|----------|-------------------|
| 英寸（in） | $39.37\,\text{in}$ |
| 英尺（ft） | $3.28084\,\text{ft}$ |
| 码（yd）   | $1.09361\,\text{yd}$ |
| 英里（mi） | $0.000621371\,\text{mi}$ |

### 1.3 米与中国传统市制单位

| 市制单位 | 换算关系（1 m =） |
|----------|-------------------|
| 里       | $1 / 500 \,\text{里}$ （即 1 里 = 500 m） |
| 丈       | $1 / 3.33 \,\text{丈}$ （约） |
| 尺       | $1 / 0.333 \,\text{尺}$ （约，即 1 尺 ≈ 0.333 m） |

## 二、质量单位换算（千克）

### 2.1 千克与常用公制单位

| 单位 | 换算关系 |
|------|----------|
| 克（g） | $1\,\text{g} = 10^{-3}\,\text{kg}$，即 $1\,\text{kg} = 10^3\,\text{g}$ |
| 毫克（mg） | $1\,\text{mg} = 10^{-6}\,\text{kg}$，即 $1\,\text{kg} = 10^6\,\text{mg}$ |
| 吨（t） | $1\,\text{t} = 10^3\,\text{kg}$，即 $1\,\text{kg} = 10^{-3}\,\text{t}$ |

### 2.2 千克与英制单位（约等）

| 英制单位 | 换算关系 |
|----------|----------|
| 磅（lb） | $1\,\text{lb} \approx 0.453592\,\text{kg}$，即 $1\,\text{kg} \approx 2.20462\,\text{lb}$ |
| 盎司（oz） | $1\,\text{oz} \approx 28.3495\,\text{g}$，即 $1\,\text{kg} \approx 35.274\,\text{oz}$ |

> 注：原资料中“常用牛顿换算法式”应为“质量换算法式”，此处已更正。

## 三、时间单位换算（秒）

### 3.1 秒与常用时间单位

| 单位 | 换算关系 |
|------|----------|
| 小时（h） | $1\,\text{h} = 3600\,\text{s}$ |
| 分钟（min） | $1\,\text{min} = 60\,\text{s}$ |
| 毫秒（ms） | $1\,\text{ms} = 10^{-3}\,\text{s}$，即 $1\,\text{s} = 10^3\,\text{ms}$ |
| 微秒（μs） | $1\,\mu\text{s} = 10^{-6}\,\text{s}$ |
| 纳秒（ns） | $1\,\text{ns} = 10^{-9}\,\text{s}$ |
| 皮秒（ps） | $1\,\text{ps} = 10^{-12}\,\text{s}$ |

> 原资料中“1ms = 5×10³”等奇怪写法应为笔误，此处按标准换算列出。

## 四、电流单位换算（安培）

**安培**（A）是电流的单位，其定义为：**每秒通过导体横截面的电荷量为 1 库仑（C）时，电流大小为 1 安培**。即：

$$
1\,\text{A} = 1\,\text{C} / 1\,\text{s}
$$

### 常用电流单位换算

| 单位 | 换算关系 |
|------|----------|
| 毫安（mA） | $1\,\text{mA} = 10^{-3}\,\text{A}$ |
| 微安（μA） | $1\,\mu\text{A} = 10^{-6}\,\text{A}$ |
| 纳安（nA） | $1\,\text{nA} = 10^{-9}\,\text{A}$ |

> 原资料中安培部分公式有误，此处已按照标准定义和常用换算修正。
