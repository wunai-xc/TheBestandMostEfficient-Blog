## 引言

打开任何一包加工食品的配料表，你几乎一定会看到一长串陌生的化学名词：山梨酸钾、焦糖色、阿斯巴甜、卡拉胶、特丁基对苯二酚……这些就是**食品添加剂**。

它们让面包松软、饮料清亮、零食酥脆、酱料浓稠，也让食品在货架上多存活几个月甚至几年。中国工程院院士曾这样评价：“**没有食品添加剂，就没有现代食品工业。** ”[reference:0]

然而，公众对食品添加剂的焦虑从未消退。“防腐剂有毒”“色素致癌”“零添加才安全”等说法在社交媒体上反复传播。2025年的一项调查显示，尽管官方记录表明过去20年规范使用食品添加剂未造成健康损害，食品添加剂在消费者食品安全担忧排名中依然居高不下[reference:1]。

这种科学与公众认知之间的鸿沟，值得认真审视。本文将从食品添加剂的定义与分类出发，系统梳理常见添加剂的功能与安全性评价体系，进而深入探讨当前最前沿的争议——肠道菌群影响、“鸡尾酒效应”与超加工食品的复杂关系。

## 第一章 什么是食品添加剂

### 1.1 定义与法律边界

按照《中华人民共和国食品安全法》的定义，食品添加剂是指“为改善食品品质和色、香、味以及为防腐、保鲜和加工工艺的需要而加入食品中的人工合成或者天然物质，包括营养强化剂”[reference:2]。

这个定义有两个关键边界需要注意：

**第一，不是所有加入食品的物质都是食品添加剂。** 只有列入《食品安全国家标准 食品添加剂使用标准》（GB 2760）或国家卫生健康委员会公告允许使用名单中的物质，才具有“食品添加剂”的法律身份[reference:3]。非法添加物（如三聚氰胺、苏丹红、吊白块）从未获得食品添加剂资格，它们属于“违法添加的非食用物质”，与食品添加剂是完全不同的概念。

**第二，食品添加剂的使用必须遵循“工艺必要性”原则。** 只有在技术上确有必要、且经过风险评估证明安全可靠的情况下，一种物质才能被批准为食品添加剂。这意味着“可加可不加”的添加剂不被允许。

### 1.2 中国食品添加剂的使用历史

食品添加剂并非现代工业的产物。中国的食品添加剂使用历史可以追溯到约6000年前的大汶口文化时期——当时酿酒用酵母中的转化酶（蔗糖酶）就是一种食品添加剂，属于食品用酶制剂[reference:4]。2000多年前的“卤水点豆腐”所用的卤水，实质上是一种食品凝固剂。蒸馒头时加入的食用碱（碳酸钠）或小苏打（碳酸氢钠），也是常见的酸度调节剂[reference:5]。

从这个角度看，食品添加剂伴随人类饮食文明走过了数千年，现代食品工业只是将其系统化、标准化了。

## 第二章 功能分类：23大类添加剂的全景

现行有效的 **GB 2760-2024** 于2025年2月8日正式实施，替代了使用10年的2014版标准[reference:6]。该标准按功能将食品添加剂分为**23大类**：

| 功能类别 | 典型作用 | 常见代表 |
|---------|---------|---------|
| 酸度调节剂 | 维持或改变食品酸碱度 | 柠檬酸、碳酸钠、乳酸 |
| 抗结剂 | 防止颗粒或粉状食品结块 | 二氧化硅、硅酸钙 |
| 消泡剂 | 降低表面张力、消除泡沫 | 聚二甲基硅氧烷 |
| 抗氧化剂 | 防止油脂氧化变质 | TBHQ、维生素E、维生素C |
| 漂白剂 | 破坏或抑制发色因素 | 二氧化硫、亚硫酸钠 |
| 膨松剂 | 使产品发起形成多孔组织 | 碳酸氢钠、明矾 |
| 着色剂 | 赋予或改善食品色泽 | 焦糖色、红曲红、柠檬黄 |
| 护色剂 | 与呈色物质作用保持色泽 | 亚硝酸钠、硝酸钠 |
| 乳化剂 | 使互不相溶的相形成均匀分散体 | 卵磷脂、单甘酯、卡拉胶 |
| 酶制剂 | 具有特殊催化功能的生物制品 | 淀粉酶、蛋白酶、转化酶 |
| 增味剂 | 补充或增强原有风味 | 谷氨酸钠（味精）、呈味核苷酸 |
| 面粉处理剂 | 促进面粉熟化、提高制品质量 | 偶氮甲酰胺（已被删除） |
| 被膜剂 | 涂抹外表起保质保鲜作用 | 蜂蜡、虫胶 |
| 水分保持剂 | 保持食品中水分 | 磷酸盐类 |
| 营养强化剂 | 补充食品中缺乏的营养素 | 维生素、矿物质、氨基酸 |
| 防腐剂 | 防止腐败变质、延长储存期 | 山梨酸钾、苯甲酸钠 |
| 稳定剂和凝固剂 | 使食品结构稳定 | 氯化镁（卤水）、硫酸钙 |
| 甜味剂 | 赋予食品甜味 | 阿斯巴甜、木糖醇、三氯蔗糖 |
| 增稠剂 | 提高黏稠度或形成凝胶 | 果胶、黄原胶、明胶 |
| 食品用香料 | 产生、修饰或提高香味 | 香兰素、乙基麦芽酚 |
| 食品工业用加工助剂 | 有助于加工顺利进行 | 氮气、活性炭、硅藻土 |
| 其他 | 上述不能涵盖的功能 | — |

[reference:7][reference:8]

截至最新统计，我国批准使用的食品添加剂有**2300多种**，其中香料种类最多，超过1800种[reference:9]。

### 2.1 常见添加剂的“身份”

了解几类最常出现在配料表中的添加剂，有助于破除一些不必要的恐惧：

**防腐剂**：山梨酸钾用于果酱、饮料；苯甲酸钠用于酱油、碳酸饮料。防腐剂的核心功能是防止食品腐败，否则有些食品“还未出厂就坏掉了，甚至还可能因为腐败产生毒素”[reference:10]。

**抗氧化剂**：TBHQ（特丁基对苯二酚）用于食用油，防止油脂酸败；维生素C和维生素E既是营养素也是抗氧化剂。

**甜味剂**：阿斯巴甜用于无糖饮料，木糖醇用于口香糖。对于糖尿病患者，高甜度甜味剂是无能量或低能量的替代方案[reference:11]。

**着色剂**：焦糖色用于可乐和酱油，红曲红用于腐乳，姜黄素用于咖喱和芥末。

**增味剂**：谷氨酸钠（味精）是最经典的增味剂，自1908年被发现以来已经过百余年的安全性审视。

## 第三章 安全性评价体系：从JECFA到GB 2760

### 3.1 国际层面的安全评估

食品添加剂的安全性不是由单一国家自行判断的。联合国粮农组织（FAO）和世界卫生组织（WHO）联合设立的**食品法典委员会**（Codex Alimentarius Commission）下设**食品添加剂法典委员会**（CCFA），负责制定统一的规格和标准，确定试验和评价方法[reference:12]。

国际层面最核心的安全评估机构是**JECFA**（FAO/WHO食品添加剂联合专家委员会）。JECFA对每种添加剂进行系统的毒理学评估，确定**每日允许摄入量**（ADI），即一个人终生每日摄入该物质而不产生可检测健康风险的量。

### 3.2 中国的制度设计

我国参照国际通行做法，建立了食品添加剂的**风险评估、风险监测和标准制修订制度**。按《食品安全法》要求，食品添加剂的生產和使用必须符合食品安全国家标准。

在制定使用范围和使用量时，我国采用与JECFA相同的原则和方法，结合食品添加剂的实际生产使用情况和我国居民的食物消费数据，开展风险评估[reference:13]。关键的安全边际设计在于：**ADI通常已经包含了100倍的安全系数**，即从动物实验的无可见有害作用水平（NOAEL）除以100得出。

这意味着，即使一个人长期、每日摄入某种添加剂达到ADI水平，理论上仍然处于安全范围。而实际摄入量往往远低于ADI。

### 3.3 GB 2760-2024的核心变化

新版标准相比2014版有几项重要调整：

**一是删除不再具有工艺必要性的品种**。落葵红、密蒙黄、酸枣色、2,4-二氯苯氧乙酸、海萝胶、偶氮甲酰胺等物质因不再具有工艺必要性，在新版中被删除，不得在各类食品中使用[reference:14]。

**二是收紧部分添加剂的使用范围**。以脱氢乙酸及其钠盐为例，新标准规定其在黄油和浓缩黄油、淀粉制品、面包、糕点、焙烤食品馅料及表面用挂浆、预制肉制品、果蔬汁（浆）中不得使用，同时在腌渍蔬菜中的最大使用量由1.0 g/kg调整为0.3 g/kg[reference:15]。

**三是将营养强化剂正式纳入食品添加剂范畴**，与GB 14880衔接[reference:16]。

## 第四章 争议与前沿：从“鸡尾酒效应”到肠道菌群

### 4.1 公众焦虑的根源

尽管官方记录表明规范使用食品添加剂未造成健康损害，公众的担忧却持续存在。2025年发表的一篇综述深入分析了这种“无根据的不安”的根源[reference:17]。

该研究认为，消费者焦虑不能由单一因素解释，而是人类历史几个重大转折点与社会结构变迁复杂交织的结果：

- **认知革命**赋予人类抽象思维和对虚构叙事的信念能力；
- **新石器革命**使农业和食物储存成为可能，也带来了食物变质问题；
- **科学革命**引入了食品添加剂和农药等新型风险；
- **信息革命**在推进信息民主化的同时，也为错误信息的传播提供了沃土[reference:18]。

这些因素相互作用，形成了科学安全评估本身难以轻易消除的深层不安。

### 4.2 “鸡尾酒效应”与超加工食品

近年来，一个更具体的担忧获得了科学关注：**多种食品添加剂同时摄入是否存在协同效应**？

传统安全性评价通常针对**单一添加剂**进行。但现实中，一个人每天可能摄入数十种不同的添加剂。法国NutriNet-Santé队列研究（2025年发表于*PLOS Medicine*）发现，某些食品添加剂混合物与**2型糖尿病发病风险显著关联**，且这种关联**与饮食的营养质量无关**[reference:19]。

这一发现具有重要的方法论意义：它提示，即使每种添加剂单独在安全范围内，多种添加剂的组合暴露仍可能产生未被单独评估涵盖的效应。

### 4.3 肠道菌群：新的靶点

肠道菌群是当前食品添加剂健康影响研究中最活跃的前沿领域。

**乳化剂**是研究最充分的类别之一。2025年巴斯德研究所发布的研究指出，广泛用于切片面包、冰淇淋、植物奶等日常食品的乳化剂，可能通过影响肠道菌群来影响个体健康[reference:20]。发表在*Food Research International*上的研究进一步表明，食品添加剂可在体外结肠发酵模型中**损害健康个体和IBD患者的肠道菌群**[reference:21]。

**二氧化钛（E171）** 是另一个焦点。2025年发表在*Toxicology in Vitro*上的研究利用人iPSC来源的结肠类器官，发现食品级二氧化钛对细胞活力和基因毒性存在影响[reference:22]。另一项研究则显示，E171可改变肠道微生物代谢活性，影响**丁酸盐产生**——丁酸盐是维持肠道屏障完整性的关键短链脂肪酸[reference:23]。

**八种常见添加剂的组合效应**是2025-2026年的一项关键研究。该研究针对此前被识别为可能诱导肠道菌群失调的八种添加剂，在体外批次发酵模型中进行了测试。结果显示，在测试剂量下，48小时发酵后对微生物多样性的影响**较小**[reference:24]。这一结果提醒我们：并非所有添加剂都会显著扰动菌群，剂量和暴露时间至关重要。

### 4.4 人工甜味剂与合成色素

2025年发表在*Europe PMC*上的一项研究聚焦于埃及儿童中流行的粉末状果味饮料，量化了人工甜味剂和合成色素的含量，发现非正规产品中添加剂滥用问题突出，揭示了**监管缺口对儿童群体的不成比例风险**[reference:25]。

在斑马鱼模型中，长期摄入**谷氨酸钠和柠檬黄**被发现可扰乱肠-脑轴，诱导代谢过程紊乱、肥胖和认知功能损害[reference:26]。虽然动物模型结果不能直接外推到人类，但这些发现为后续的机制研究提供了方向。

## 第五章 理性看待添加剂：在证据与直觉之间

### 5.1 “零添加”的迷思

“不含防腐剂”“零添加”是营销中最常见的卖点之一。但从食品安全角度看，这一逻辑存在根本问题。

防腐剂的核心功能是防止腐败微生物生长。没有防腐剂，某些食品可能在到达消费者手中之前就已经变质，甚至产生**微生物毒素**——这些毒素的健康风险远高于合规使用的防腐剂本身[reference:27]。

当然，也有一些食品确实不需要防腐剂，因为它们本身**不具备腐败微生物宜居的环境**——蜂蜜（高糖）、干燥食品（低水分活度）、高酸性食品（如果汁中的柠檬酸环境）天然具有抑菌能力。这些食品声称“不含防腐剂”是事实陈述，但不意味着它们比含防腐剂的同类产品“更安全”[reference:28]。

### 5.2 科学共识与不确定性

当前主流科学界的共识可以概括为：

**规范使用是安全的。** 按照GB 2760规定的品种、范围和限量使用食品添加剂，经过系统的风险评估和持续的动态跟踪评价，不会对健康造成危害[reference:29]。

**但共识有边界。** 以下领域仍存在科学不确定性：
- 多种添加剂的**联合暴露效应**尚未被系统评估；
- 添加剂对**肠道菌群**的长期影响仍在研究中；
- **超加工食品**作为一个整体（而非单一添加剂）的健康效应需要进一步厘清。

**超加工食品≠食品添加剂。** 这是公众讨论中最常见的概念混淆。超加工食品的健康风险可能更多来自其**高糖、高脂、高盐、低纤维**的营养特征，以及加工过程中营养成分的损失，而非添加剂本身。将超加工食品的所有问题归咎于添加剂，在科学上是不准确的。

## 总结

食品添加剂是现代食品工业不可或缺的组成部分。GB 2760-2024以23大类功能分类和严格的工艺必要性原则，构建了从品种审批到使用限量的完整监管框架。国际层面的JECFA评估和国内的持续动态跟踪评价，为“规范使用安全”这一结论提供了制度保障。

但科学共识并不意味着一切问题都已解决。“鸡尾酒效应”、肠道菌群影响、超加工食品的整体健康效应等前沿问题，正在推动安全性评价方法论的演进。公众的焦虑虽然部分源于信息传播的扭曲，但也确实指向了传统风险评估框架尚未充分覆盖的领域。

理解食品添加剂，需要的不是简单的“相信科学”或“恐惧化学”，而是在具体证据的边界内做出判断的能力。**风险的本质是概率和剂量的函数，而非“天然”或“合成”的标签。**
